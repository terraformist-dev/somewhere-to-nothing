# Nothing Playground listing

Files for sharing the Glyph Toy on Nothing Playground / the Nothing Community.

| File | What it is |
|---|---|
| `somewhere-to-nothing-preview.png` | 512×512 still of the Glyph Matrix (needle pointing to the store). |
| `somewhere-to-nothing.json` | 5-second, 30 fps Lottie animation of the toy (150 frames). |
| `somewhere-to-nothing-animation-preview.gif` | The same animation as a GIF, for looking at on a phone. Not for uploading. |
| `make_playground_assets.py` | Draws all of the above, using the same rules as `MatrixArt.kt`. |

The animation: the needle swings round to find the store, a long-press shows the distance
(1.2 KM), the pulse quickens as you get closer, then the ring pulses when you arrive. It loops.

The look (black disc, square pixels, unlit pixels #1C1C1C) matches the Phone (3) Lottie export of
[GlyphMatrixEditor](https://github.com/pauwma/GlyphMatrixEditor), which is made for Nothing Playground.
